# 모델 간 작업 인계

Claude와 Codex(또는 새 세션)가 작업을 넘길 때만 쓰는 얇은 상태 계층이다. Task Team·Bug Team의 상세 산출물을 대체하거나 복제하지 않는다. 절차는 `docs/agent-contracts/handoff.md`.

## 사용 규칙

1. Claude 또는 Codex에서 평소처럼 작업한다.
2. 다른 모델이나 새 세션이 실제로 이어받아야 할 때만 `work/{work-id}/`를 만든다.
3. 전환 직전에 `STATUS.md`와 `HANDOFF.md`를 갱신한다(형식: `work-item-template.md`).
4. 다음 담당자는 두 파일과, 거기서 참조한 산출물·코드만 추가로 읽는다.
5. 끝난 work-id는 사람 확인 후 `artifacts/archive/work/`로 옮긴다.

## 파일 계약

| 파일              | 작성 시점                        | 목적                                     |
| ----------------- | -------------------------------- | ---------------------------------------- |
| `STATUS.md`       | 전환 직전 (필수)                 | 담당, 브랜치, 단계, 차단 사유, 다음 행동 |
| `HANDOFF.md`      | 전환 직전 (필수)                 | 결정, 변경 파일, 검증 결과, 미해결 항목  |
| `DECISIONS.md`    | 결정이 여럿이거나 오래 참조할 때 | 확정 결정과 근거 누적                    |
| `PLAN.md`         | 복잡한 실행 계획을 넘길 때       | 단계, 변경 대상, 검증 계획               |
| `VERIFICATION.md` | 검증 기록이 길거나 반복될 때     | 실행한 명령과 결과                       |

## 기존 산출물 참조

- 기능 개발: `artifacts/task-team/{run id}/`를 `HANDOFF.md`에서 경로로 참조한다.
- 버그 처리: `artifacts/bug-team/{run id}/`를 경로로 참조한다.
- 같은 내용을 이 폴더에 다시 복사하지 않는다.
